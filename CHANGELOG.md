# Changelog

Todos los cambios relevantes de este proyecto se documentan en este fichero.

El formato sigue [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/) y el proyecto usa [Versionado Semántico](https://semver.org/lang/es/).

## [0.1.0] - 2026-10-15

### Añadido

- Listado de reservas con filtro por sala y por rango de fechas (#1).
- Formulario de nueva reserva con validación de franja y fecha (solo a partir de mañana) (#1).
- Pantalla de detalle de una reserva en `/reservas/:id` (#2).
- Cancelación de reservas desde el listado y desde el detalle, con diálogo de confirmación accesible y aviso al terminar (#2).
- Páginas de error: servicio no disponible, error inesperado, sin permiso y página no encontrada (#13).
